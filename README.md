# Day 01 - Trading Profit Calculator 📈

My first Python project!

## Kya Karta Hai Ye?
Ye calculator batata hai ki tumhe trading me kitna Profit ya Loss hua.

## Kaise Chalayein?
1. `main.py` ko run karo
2. Buy Price dalo
3. Sell Price dalo
4. Kitne shares liye wo dalo

## Example
Buy Price: 100
Sell Price: 120
Shares: 10

**Result: Total Profit: 200 Rs ✅**

## Maine Kya Seekha?
- `input()` se user se data lena
- `float()` aur `int()` ka use
- `if / elif / else` se condition check karna
